Backend API:

Dashboard đọc từ Backend REST (/api/status). Backend tự lấy dữ liệu từ MQTT Broker. Realtime dùng SSE (/api/stream) — tự kết nối lại khi rớt mạng.

Endpoint có sẵn

GET /api/status — sơ đồ realtime · GET /api/stats — thống kê doanh thu
GET /api/receipts — hóa đơn · GET /api/bookings — đặt chỗ · GET /api/rfid — thẻ
POST /api/booking — đặt/hủy · POST /api/gate — barrier · POST /api/enter · POST /api/exit
POST /api/auth/register · POST /api/auth/login · GET /api/users · POST /api/balance
